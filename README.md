## 注意
- 非公式サイトです。
- 未確認情報・リークは確定情報ではありません。
- 元情報や報道内容はリンク先で確認してください。

## 炎上監視・記事採用ルール
ハラ・スタレ・ゼンゼロ・HoYoverseについて、運営や企業の不祥事だけでなく、公式投稿・公式イラスト・キャラクター描写などを発端として海外または日本のコミュニティで大規模に拡散した論争、Ship War、カップリング論争、ファンダム騒動も炎上監視対象とする。単発の小規模な口論は採用せず、一定以上の拡散・反応が確認できるものを対象とする。拡散規模は元投稿や関連投稿の閲覧数・いいね・リポスト・返信、複数コミュニティへの波及、関連報道など実際に確認できた根拠で判断し、固定の数値や反応を推測で作らない。公式に確認できる事実とファン側の解釈・主張は明確に分離して記事化する。公式発信の内容を先に示し、ファンの主張は「〜と受け取った」「〜という解釈が広がった」など主張として記述し、非公式カップリングを公式設定と断定しない。RSS候補の有無だけで監視を終えず、公式発信を巡る日本語・英語・中国語のXや公開コミュニティの話題を検索して補う。RSSにない場合も十分な拡散と根拠を確認できた新規の騒動は既存の炎上カテゴリへ追加する。規模を確認できない候補は記事化せず、既存の充実した記事を保護する。

## 中国ゲーム枠・朝のブリーフからの反映
- 「中国ゲーム・最新」は個別タイトルの新情報、「中国ゲーム業界」は企業・市場・規制・投資に加え、複数社の商戦、リアルイベント、宣伝施策、商業施設との連携も対象とする。具体的な日付・出来事・出典を確認できるものを採用し、一般論だけで記事を増やさない。
- 朝の鳴潮デイリーブリーフで紹介した保存価値のある中国ゲーム情報は、ブリーフで報告しただけで反映済みと扱わない。記事ID・出典URL・出来事を最新の data/news.json と照合し、未掲載分を差分統合してコミットする。
- 保存後は最新の data/news.json を再取得し、追加した記事ID・カテゴリ・本文を確認する。報告は「掲載済み」「追加成功」「未反映・確認不能」を区別し、未反映の場合は理由を示す。
- 夜更新は当日の朝に保存済みの記事と出典を再利用し、続報や不足だけ補完する。未掲載が分かった過去のブリーフ項目を補完する場合、元の公開・発表日を維持して新着ニュースに見せない。
- 保存済み記事はRSSの新規採用フィルタで削除せず、RSS再取得で調査済み本文・時系列・反応を上書きしない。専用カテゴリを優先し、同一内容を複数カテゴリへ重複登録しない。
