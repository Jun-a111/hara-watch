# KURO WATCH（自動収集対応版）

これは既存サイトの**別バージョン**です。既存の `chatgpt.site` は自動で書き換わりません。

## 自動更新の仕組み
- GitHubの公開リポジトリに、このフォルダの中身をアップロード（隠しフォルダ `.github/` を含める）。
- リポジトリの **Settings → Pages** から **Deploy from a branch** / `main` / `/(root)` を選ぶ。
- **Actions** を有効にする。**Actions → KURO WATCH daily news → Run workflow** で初回取得。
- 翌日以降は概ね日本時間 06:10 ころにGitHub Actionsが RSS を確認し、`data/news.json` に保存する（実行時間は保証されません）。
- Github PagesのURLで閲覧する。独自ニュースの追加・編集はブラウザごとの保存で、別端末への同期にはJSONバックアップを使う。

**重要：** GoogleニュースRSSのタイトル・媒体名だけを収集し、元記事を読んだかのような自動要約は生成しません。RSS由来の情報は「報道」扱い、噂・リーク語句を検出した記事は「未確認」扱いにします。この判定は機械的な暫定分類であり、出典や正確性を確認した保証ではありません。RSSを配信元から取得できない日は既存データを保持します。リークの完全なフィルタ・ネタバレ防止を保証するものではありません。自動公開にはGitHubアカウントでの設定が必要です。
